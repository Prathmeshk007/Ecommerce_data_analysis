# 📊 End-to-End Data Analytics Project

## 🚀 Overview
Complete workflow for Ecommerce data analytics using **Excel → Python → SQL → Power BI**.

## 🔄 Project Flow
1. **Excel** → Raw dataset  
2. **Python (Pandas)** → Cleaning & feature engineering  
3. **Export Clean Data** → Excel/CSV  
4. **MySQL** → Store & query data  
5. **Power BI** → Build dashboard  

## 🐍 Python
- Handle missing values, duplicates, invalid entries  
- Clean strings, emails, dates, numerics  
- Feature engineering: Sales, Net Amount, Profit, Month, Year, Weekday  
- Export cleaned dataset  


## 📈 Power BI
- Import SQL table  
- Measures: Total Sales, Profit, Orders, AOV  
- Visuals: KPIs, Monthly Trend, Top Products, Sales by City/Category, Payment Mode, Order Status  



## 🎯 Key Learnings
- Data cleaning with Python  
- SQL analysis for KPIs  
- Power BI dashboards for insights
